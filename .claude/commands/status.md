# État du projet d'écriture

Analyse l'état actuel du projet d'écriture en cours.

## Instructions

1. Cherche un fichier `projet.md` dans le dossier courant ou ses sous-dossiers
2. Si trouvé, lis-le et analyse l'état d'avancement
3. Cherche aussi tout fichier pertinent : chapitres, fiches personnages, notes, brouillons
4. Fais un inventaire de ce qui existe

## Rapport à produire

```
ÉTAT DU PROJET — [titre]

Dernière activité : [date du dernier fichier modifié]

COMPLÉTÉ :
- [x] [élément] — [fichier correspondant]

EN COURS :
- [ ] [élément] — [état actuel]

À FAIRE :
- [ ] [élément]

PROCHAINE ÉTAPE RECOMMANDÉE :
[action] → Agent suggéré : /[commande]
```

Si aucun fichier `projet.md` n'est trouvé, suggère de lancer `/nouveau-projet` pour initialiser.
