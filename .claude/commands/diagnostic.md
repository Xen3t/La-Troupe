# Diagnostic complet d'un texte

Lance un diagnostic en deux passes sur le texte fourni :

## Passe 1 — Script Doctor

Lis et applique le rôle défini dans `la-troupe/core/script-doctor/SKILL.md`.

Produis un **rapport de diagnostic** complet :
- Verdict global
- Problèmes critiques avec pistes de correction
- Problèmes secondaires
- Ce qui fonctionne
- Priorité de correction

## Passe 2 — Étranger

Puis bascule sur le rôle défini dans `la-troupe/core/etranger/SKILL.md`.

Produis un **rapport de lecture froide** :
- Première impression
- Ce que tu as compris (en tant que lecteur sans contexte)
- Ce que tu n'as pas compris
- Ce qui t'a accroché / décroché
- Impressions brutes sur les personnages

## Synthèse

Termine par une **synthèse croisée** de 5-10 lignes : où est-ce que les deux diagnostics convergent ? Quels sont les problèmes identifiés par les deux passes ?
